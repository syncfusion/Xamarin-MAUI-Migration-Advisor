20 days until the Google Play deadline

Google Play: from 31 August 2026, new apps and updates must target Android 16 (API 36); an extension is available to 1 November 2026. Xamarin.Android cannot target API 36.
App Store: since 28 April 2026, App Store Connect requires builds made with Xcode 26 and the iOS 26 SDK. Xamarin.iOS cannot produce them.
A Xamarin app is not simply unsupported — it cannot ship updates to either store.

What this excludes

New features, UI redesign, QA and regression cycles, store resubmission and review, team ramp-up on MAUI, and any backend work. It also assumes the app currently builds.

And how the readiness score was calculated

The score measures blocker density, so a large application is not penalised simply for being large:

penalty = (10 × 8) + (4 × 15) + (1 × 14) + (0.2 × 12) = 156.4
scale   = 40 + (8 × 6 projects) + (0.4 × 10 source files) = 92
score   = 100 × e−penalty/scale = 18

Those constants are judgement rather than measurement. They are printed here so you can disagree with them and recompute.

Suggested sequence

  1. Deal with the projects the Upgrade Assistant will not touch first. UWP heads, iOS extensions and binding projects drive the timeline, and finding them late is what turns an eight-week migration into a five-month one.
  2. Resolve blocked packages before writing any code. A dependency with no MAUI path is an architectural decision, not a porting task.
  3. Run the .NET Upgrade Assistant on the shared project and the mobile heads. Expect it to handle project files and namespaces, and nothing platform-specific. Note that the official documentation is stale — it was last updated in January 2024 and still retargets to net8.0, which left support in May 2025. Retarget to a current TFM yourself.
  4. Port renderers to handlers. Take the highest-traffic screens first so you get a shippable build early.
  5. Replace removed APIs. Application.Properties deserves care: without a one-time upgrade path, existing users lose their stored data on update.
  6. Clear the compatibility namespace. Microsoft.Maui.Controls.Compatibility does not ship in .NET 11. Anything left behind here blocks that upgrade.
  7. Ship to both stores before the deadlines. Store review is not instant; work back from 31 August, or 1 November if you take the Play extension.
Method and limits. This is static text analysis, not compilation. It finds patterns in project files, C# and XAML; it cannot see runtime behaviour, reflection, source generators, or anything behind conditional compilation. Treat the output as a scoped starting point for planning, not a guarantee of completeness. Findings are evidence-linked so every one can be checked by opening the file at the stated line.
Privacy. Nothing is uploaded and nothing leaves this machine. The tool makes no network calls. The HTML report contains file paths and short code excerpts from your solution — review it before sharing outside your team.
